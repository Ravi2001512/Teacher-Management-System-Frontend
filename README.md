# TeachGrid Frontend

This repository contains the frontend code of the TeachGrid web application. TeachGrid is an educational platform designed to provide a modern, interactive, and user-friendly experience for students and administrators.

## 🚀 Technologies

*   **Core:** React 19, Vite 7
*   **Styling:** Tailwind CSS, PostCSS
*   **Routing:** React Router v7
*   **Networking:** Axios
*   **UI Components & Icons:** Lucide React
*   **Data Visualization:** Recharts
*   **Notifications:** React Hot Toast / React Toastify
*   **Report Generation:** jsPDF, jsPDF-AutoTable

## 📦 Prerequisites

Ensure you have the following installed to run this project:
*   [Node.js](https://nodejs.org/) (v18 or higher recommended)
*   npm or yarn

## 🛠️ Setup & Installation

1.  Clone the repository and navigate to the project directory:
    ```bash
    git clone <repository-url>
    cd wahs_01_teachgrid_frontend
    ```

2.  Install dependencies:
    ```bash
    npm install
    # or
    yarn install
    ```

## 🏃‍♂️ Development Station

Start the development server:

```bash
npm run dev
# or
yarn dev
```
The application will launch and typically be available at `http://localhost:5173/`.

## 🏗️ Build & Preview

To create a production build:

```bash
npm run build
# or
yarn build
```

To preview the locally generated production build:

```bash
npm run preview
# or
yarn preview
```

## 📝 Available Scripts

*   `npm run dev` - Starts the Vite development server.
*   `npm run build` - Builds the application for production to the `dist` folder.
*   `npm run lint` - Runs ESLint to check for potential code issues.
*   `npm run preview` - Boots up a local server to preview the production build.
